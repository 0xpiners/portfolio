#### Description

There is a nice program that you can talk to by using this command in a shell: `$ nc mercury.picoctf.net 21135`, but it doesn't speak English...

When we connect to the service, it gives us a bunch of numbers that look like ASCII values. Let's grab them all and decode using CyberChef.
